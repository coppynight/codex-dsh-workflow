# Cost and intervention experiment v3 — frozen before inference

Question: can Astra retain planning and acceptance while a less expensive executor reduces the cost of an accepted delivery, without increasing user intervention?

One new three-file offline job-report CLI task; the full requirements are in case.mjs. visible-test.mjs has three public assertions. acceptance.mjs has 17 independent checks, frozen before either executor runs and withheld until final scoring. The suite is an acceptance sample, not proof of all behavior (for example exclusive creation is also reviewed in source).

Both arms share one measured Astra plan, charged once to each counterfactual delivery but only once in the actual experiment spend ledger. A uses Astra to implement; B uses DeepSeek v4 Flash through DSH. Both receive the same requirements, plan and visible test. Fresh Astra acceptance sessions see identical-format requirements, plan, sources and actual visible-test results, with executor identity omitted. They return a verdict and actionable findings, never a complete rewritten implementation. At most one repair round goes to the original executor, followed by a fresh acceptance session. All attempts and failures count. Hidden tests run after review, and their feedback is not used to selectively improve either arm.

Astra CLI tool execution was rejected by the environment in the earlier pilot. This experiment does not relax that policy: Astra stages return structured data without tools; an external deterministic harness writes sources and runs the visible test. DSH uses its normal file and test tools. Thus this is a controlled task-partition experiment, not a full native Codex product or subscription benchmark. The shell harness's actions, experiment design, main conversation, data curation and publication are outside measured model stages. Report those exclusions, and do not present the resulting ratio as complete end-to-end production savings.

Record input/cache/output separately; reasoning is a subset of output. Price with the dated official rates and each DSH turn's peak/off-peak interval; report a range if the exact interval is unavailable. Astra API-equivalent dollars and weighted Codex credits are estimates, not the subscription's observed quota debit. Include the executor's extra expense, failed attempts and repair. Report elapsed stage time separately from cost. A completed delivery must pass all frozen tests and have no unresolved blocking review finding.

User intervention means an actual request requiring a person to decide, approve, supply information, configure credentials or repair the environment. Count events, category and resolution; absence in one healthy run is not evidence of a reduction. Parent agent/harness operations are not human interventions. Fault-injection tests are a separate recovery-mechanism experiment; expected manual actions are not observed human time. Do not infer 5x/10x/20x subscription capacity or a percentage reduction in human work from this one case.

Preserve original outputs and prompts, sanitized numerical usage, tests and hashes. Do not publish raw internal reasoning, credentials or private runtime logs. A poor result remains in the dataset. Optimize task routing or acceptance behavior only in a new, separately labeled protocol/run.
